# Restore Local Artifacts

The upload did not delete local files. It only excludes large or generated
artifacts from Git. On this machine, ignored folders such as `datasets/`,
`external/`, `model1/`, `runs/`, and `wandb/` remain in place unless removed by
hand.

This document describes how to rebuild a fresh clone into a runnable workspace.
Log files are intentionally not restored.

## 1. Restore Curated Project Checkpoints

The most important small project-owned checkpoints are tracked under
`checkpoints/curated/`. Restore them to the legacy paths used by older scripts:

```bash
bash scripts/restore_curated_checkpoints.sh
```

This restores:

- V2X-Sim all-agent and leave-one-agent checkpoints.
- V2X-Sim ablation checkpoints.
- DAIR-V2X VSPM delay-grid, MST ablation, and sensitivity checkpoints.

It does not restore every training epoch. The full epoch history remains a
local generated artifact.

## 2. Restore Third-Party Repositories

The `external/` directory is intentionally ignored because each subdirectory is
an independent upstream checkout plus local data/checkpoint state. Recreate the
checkouts only when needed:

```bash
mkdir -p external
git clone https://github.com/AIR-THU/DAIR-V2X.git external/DAIR-V2X
git clone https://github.com/ChengchangTian/DATA.git external/DATA
git clone https://github.com/JesseWong333/LRCP.git external/LRCP
git clone https://github.com/ai4ce/DiscoNet.git external/DiscoNet
git clone https://github.com/MediaBrain-SJTU/SyncNet.git external/SyncNet
git clone https://github.com/coperception/coperception.git external/coperception
git clone https://github.com/open-mmlab/mmdetection3d.git external/mmdetection3d-v0.17.1
```

Some local external checkouts had uncommitted local patches. Those patches were
not uploaded into this repository. Preserve them separately if they are needed
for exact reproduction.

## 3. Restore Official External Checkpoints

Official OpenDAIRV2X/DATA detector checkpoints are not uploaded here because
they are external dependencies and some are very large. Restore the DAIR
official checkpoints with:

```bash
bash scripts/download_dair_v2x_checkpoints.sh
```

DATA/OpenCOOD checkpoints produced by `scripts/run_data_v2xsim_pipeline.py`
should be regenerated by rerunning that pipeline, or copied from an existing
local workspace if available.

## 4. Restore Datasets

Place datasets back under the ignored local paths:

```text
V2X-Sim-det/
datasets/DAIR-V2X/
datasets/V2X-Sim-2.0/
```

For V2X-Sim BEV occupancy experiments, `V2X-Sim-det/` must contain:

```text
train/agent1 ... train/agent5
test/agent1  ... test/agent5
val/agent1   ... val/agent5
```

For DAIR-V2X-C, use the local download/preparation scripts:

```bash
bash scripts/download_dair_v2x_c_until_complete.sh
bash scripts/prepare_dair_v2x_layout.sh
```

Then check the resulting layout:

```bash
bash scripts/check_dair_v2x_prereqs.sh
```

## 5. What Is Not Restored

The following are intentionally excluded and should normally be regenerated:

- `*.log`, `*.latest_log`, and wandb offline logs.
- `*.pid` process files.
- raw prediction dumps such as `.npy`, `.npz`, and `.pkl`.
- local download caches and partial files.
- full training epoch histories beyond the curated checkpoints.
